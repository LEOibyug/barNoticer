# 供应商配置

真实 SwiftUI 设置组件离屏渲染，使用虚构配置且禁用联网发现，不是用户凭据截图。configured-dark.png 展示有值时不显示示例；empty-light.png 展示框内灰色占位符。自动测试同时检查四个文本输入框等宽。

支持供应商名称、Base URL、响应协议、API Key、模型；编辑配置与实际使用配置分开。单配置模式使用指定配置；按顺序模式从列表首项尝试，可上移/下移。设置自动持久化，旧单配置迁移为第一套。

URL 和 Key 就绪后延迟 650ms 查询模型列表，模型名支持大小写不敏感的前缀补全。探测常见余额接口，无法识别或接口不支持时显示“暂无数据”。测试仅使用当前编辑配置，分别检查文字响应和随机数字图片识别，不使用真实任务数据，不执行任务工具。
