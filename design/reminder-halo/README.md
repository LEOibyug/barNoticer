# Reminder halo

2026-10-08：由真实 ReminderHaloView 在本地离屏渲染的峰值外观，黑色示意岛用于检查背景对比；不是运行中窗口截图。dark.png / light.png 分别检查深浅桌面背景。

蓝紫渐变轮廓配双层高斯柔光（5 pt 内层、16 pt 外层，18 pt 发光笔画），仅在布局时生成位图；播放时只动画透明度。光晕在 1.2 秒内淡入、保持亮度并消退，完成后再展开提醒面板。提醒示例、实际提醒、AI 回复使用同一时序，系统通知也在光晕后发出。64 pt 绘制边距用于避免扩散光晕裁剪。

提醒设置新增“光晕边界”：自动跟随收起的岛并沿用原外扩设置，或使用自定义水平/向下偏移、宽高和圆角。支持数值输入、逐点调整、持续参考线，以及一键对齐收起的岛。切换自动/自定义时保留手动数值，预览和真实提醒使用同一套持久化几何。

静态预览使用可见边界，不播放光效；减少动态效果时真实提醒、AI 回复和提醒示例均跳过光晕。降低透明度时省略模糊柔光，提高对比度时加粗轮廓。辅助功能设置变更时清理在途光晕。
